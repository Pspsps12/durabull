## Purpose

Durabull currently includes temporary startup migration logic that encrypts legacy plaintext Redis connection URLs on boot.

After all deployed environments are migrated and verified, this temporary logic should be removed from the repository.

## Exit Criteria Before Cleanup

Run these checks in every environment (prod, staging, any long-lived preview stacks):

1. `bun tooling/scripts/encrypt-redis-connection-urls.ts --dry-run`
2. Confirm output:
   - `migrated from plaintext: 0`
   - `invalid encrypted rows: 0`
3. Restart API and confirm startup is clean.

Do not remove migration code until all environments pass.

## Remove Temporary Startup Migration Code

Delete or revert the following temporary code paths:

1. Startup migration toggle and branching logic:
   - [redis-url-encryption-audit.ts](/Users/gregg/dev/durabull/packages/dal/src/db/redis-url-encryption-audit.ts)
